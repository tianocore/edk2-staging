# Authenticated Variable Files (.auth)

This directory contains authenticated variable update files (.auth) used to update Secure Boot keys in **Standard Mode** (User Mode).

Generated by: `EmulatorPkg\Test\SecureBootPQC\Tools\generate_auth_var.py`

## Overview

In UEFI Secure Boot Standard Mode (User Mode), updating Secure Boot variables (PK, KEK, db, dbx) requires proper authentication. The variables must be wrapped in an `EFI_VARIABLE_AUTHENTICATION_2` structure with a valid PKCS#7 signature.

## Naming Rule

prefix == content algo, suffix == signature algo.
Multiple algorithms can be concatenated with "-". Algorithm order does not matter.
Composite Algo name should not include "-".

## EFI_VARIABLE_AUTHENTICATION_2 Structure

According to UEFI Specification 2.10 Section 8.2.2, the authenticated variable format is:

```c
typedef struct {
  EFI_TIME                    TimeStamp;      // 16 bytes
  WIN_CERTIFICATE_UEFI_GUID   AuthInfo;       // Variable size
  // UINT8                    Data[...];      // Actual variable data (EFI_SIGNATURE_LIST)
} EFI_VARIABLE_AUTHENTICATION_2;
```
